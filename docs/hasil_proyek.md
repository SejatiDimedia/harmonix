# Hasil Proyek & Kemampuan Unggulan: Harmonix

Ringkasan hasil proyek dan fitur unggulan yang dirancang untuk halaman portofolio, proposal klien, maupun profil profesional.

---

## Versi Bahasa Indonesia

### 4 Kemampuan Utama Aplikasi
* **Tanya Data Pakai Bahasa Sehari-hari, Langsung Jadi Tabel dan Grafik**  
  Pengguna cukup mengetik pertanyaan seperti biasa tanpa perlu paham SQL. Sistem langsung memberikan ringkasan temuan penting, tabel data yang rapi, dan grafik visual interaktif (batang, garis, donat) yang siap dipakai untuk bahan presentasi.
* **Satu Klik Simpan ke Dasbor dengan Mode Layar Penuh untuk Ruang Rapat**  
  Grafik atau tabel hasil analisis bisa langsung disematkan ke dasbor dalam satu klik. Dilengkapi mode layar penuh yang otomatis menyesuaikan ukuran TV atau proyektor ruang rapat tanpa terpotong dan tanpa perlu scroll.
* **Klik Grafik untuk Menelusuri Akar Masalah (*Chart Drill-Down*)**  
  Grafik yang dihasilkan bersifat interaktif. Saat melihat ada penurunan performa atau tren yang mencurigakan, pengguna cukup mengeklik bagian grafik tersebut untuk langsung menelusuri penyebabnya, memecah data per cabang, atau melihat data mentahnya tanpa perlu mengetik ulang pertanyaan.
* **Unggah File Excel atau CSV Sendiri Lengkap dengan Cek Kualitas Data**  
  Pengguna bisa mengunggah file spreadsheet sendiri (termasuk file dengan banyak sheet). Sistem otomatis memeriksa data yang kosong, mendeteksi angka janggal lewat Skor Kesehatan Data (0–100), dan menyiapkan data tersebut untuk langsung dianalisis mandiri.

### Dampak untuk Bisnis
* **Pangkas Waktu Tunggu Laporan:** Permintaan data yang biasanya memakan waktu berhari-hari kini bisa dijawab langsung dalam hitungan detik.
* **Database Tetap Aman:** Data operasional terlindungi dari risiko salah hapus atau salah ubah karena akses dikunci hanya untuk membaca, ditambah penyensoran otomatis untuk data pribadi pelanggan.
* **Bebas Masalah Halusinasi AI:** Angka hasil analisis terbukti akurat dan konsisten (skor kesesuaian 94,2%) berkat sistem verifikasi mandiri yang selalu mencocokkan teks penjelasan dengan data aslinya sebelum ditampilkan.
* **Bebas Biaya Langganan:** Sistem dapat berjalan mandiri di server lokal tanpa ketergantungan pada API berbayar, sehingga biaya operasionalnya nol rupiah.

## English Version

### 4 Standout Capabilities
* **Ask in Plain Language, Get Instant Tables and Interactive Charts**  
  Users simply type questions in everyday language without needing to know SQL. The system immediately delivers key findings, structured data tables, and interactive visual charts (bar, line, donut) ready for presentations.
* **One-Click Pin to Dashboard with Fullscreen Mode for Meeting Displays**  
  Any chart or table from the analysis can be pinned to the dashboard in a single click. It includes a dedicated fullscreen mode that automatically fits meeting room TVs and projectors without awkward cutoffs or scrolling.
* **Click Any Chart to Investigate Root Causes (*Chart Drill-Down*)**  
  Charts are fully interactive. When spotting a performance dip or an unusual trend, users can click directly on the chart to investigate the root cause, break down numbers by branch, or inspect raw rows without retyping the question.
* **Upload Excel or CSV Files with Automated Data Quality Checks**  
  Users can upload their own spreadsheets (including multi-sheet files). The system automatically audits missing entries, detects anomalies through a Data Health Score (0–100), and prepares the dataset for immediate standalone analysis.

### Business Impact
* **Eliminate Reporting Bottlenecks:** Queries that usually take days of waiting are answered directly in seconds.
* **Keep Operational Data Safe:** Core business data is protected against accidental deletion or modification with strict read-only access, alongside automated masking for customer personal data.
* **Eliminate AI Hallucinations:** Delivers verified numerical accuracy (94.2% factual consistency score) through an independent verification system that cross-checks narrative explanations against raw data before display.
* **Zero Recurring API Fees:** Runs self-contained on local infrastructure with zero paid cloud API dependencies, keeping operational compute costs at zero dollars.
